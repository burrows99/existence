# existence

A universe you can zoom into anywhere, where everything is genuinely made of the level below it.

**Live: https://burrows99.github.io/existence/**

Scroll on anything to zoom into it. Right now it starts inside a drop of water with a few real biomolecules drifting through. Keep scrolling: the protein is its 2,541 real atoms (hydrogens included), each atom dissolves into its electron cloud sampled from real orbitals with the nucleus at the centre, the nucleus is its protons and neutrons, and each of those is three quarks. Every spot is a link.

Nothing is stored. Every object regenerates the same contents from a seed when you look at it, so a cell of 10¹⁴ atoms costs nothing until you zoom into one of them. See [PLAN.md](PLAN.md) for how it works and what comes next (cells, a body, Earth, the solar system, galaxies, the observable universe).

## Run it

```bash
npm install
npm run dev     # http://localhost:5173/existence/
npm test        # checks the orbital maths
```

React 19 · [react-three-fiber](https://github.com/pmndrs/react-three-fiber) · three.js. Structures from the [RCSB PDB](https://www.rcsb.org/) and [PubChem](https://pubchem.ncbi.nlm.nih.gov/); element data from [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON).
